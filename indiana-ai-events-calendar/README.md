## 9. Turning This Into a Google Sheets Filterable Tracker

1. Open Google Sheets → **File → Import → Upload** → select `events.csv`.
2. Choose **Insert as new sheet** (or replace current sheet) and import.
3. Select the header row → **Data → Create a filter**.
4. Add filter views for the columns you'll use most:
   - **City** (Insert → Filter views → filter by "City")
   - **Event Type**, **Cost**, **Target Audience**, **LegacyOps Relevance (1-5)**, **Distance from Brownsburg 46112**
5. Optional: conditional formatting on the **LegacyOps Relevance (1-5)** column (Format → Conditional formatting → color scale, red=1 to green=5) so high-value events jump out visually.
6. Optional: add a checkbox column ("Registered?" / "Attended?" / "Followed up?") via Insert → Checkbox for your own tracking.

**Airtable / Notion:** both platforms support direct CSV import (Airtable: Add a table → Import data → CSV; Notion: New page → Import → CSV). Column types will import as text by default — recast the Date column as a Date field and Relevance as a Number field for sorting.

## 10. Adding Selected Events to Google Calendar

**Option A — import the whole .ics file:**
1. Google Calendar → gear icon → **Settings → Import & export → Import**.
2. Choose `legacyops_indiana_ai_calendar.ics`, select the calendar to add it to, click **Import**.
3. All 14 dated events + 3 monthly "monitor check" reminders will appear. Delete any you don't want individually afterward.

**Option B — add just one event manually:**
1. In Google Calendar, click **Create → Event**.
2. Copy the event name, date, time, and location from the table above or `events.csv`.
3. Paste the registration link into the "Description" field, and set a reminder for 3–7 days before (to register) plus 1 day before (to prepare).

I did not push anything to your actual Google Calendar — the `.ics` file is a template for you to review and import yourself, since only you should decide which of these go on your calendar.
