# Proof to Possibility — Showcase

An AI-native career showcase: interactive command center + video + discussion deck.
`index.html` is the working prototype of the command center — a single self-contained
file with no dependencies. Open it in any browser, host it anywhere (SharePoint,
GitHub Pages, Power Pages, or behind a QR code).

## What's in the prototype

Seven screens, matching the experience blueprint:

1. **Home** — thesis + three initiative cards
2. **Impact Map** — capability evolution (not a job-history timeline)
3. **Case Studies** — Context → Need → Role → System → Evidence → Reuse
4. **Systems** — animated DRIPS loop (Detect → Root cause → Improve → Prove → Share)
5. **AI Stack** — one clear job per tool
6. **Role Fit** — role filters that highlight supporting evidence
7. **Connect** — discussion prompts + QR/contact placeholder

## Production sequence (three sessions)

1. **Story & evidence** — collect approved screenshots, numbers, and stakeholder
   quotes into one folder; finalize the case-study copy in `index.html`.
2. **Polish & video prep** — apply final visual tweaks, record a screen-capture
   walkthrough of the command center, build the Synthesia avatar scenes.
3. **Publish** — assemble the 4-minute master + 90-second cut in Canva, generate
   the QR code, export the 7-slide discussion deck (each deck slide = one screen
   of this experience).

## Why this beats starting in Figma or a platform build

- It already works — clickable today, on any device, zero licenses needed to view.
- One file = easy to sanitize, duplicate, and version (internal vs. external).
- It *is* the AI-native proof point: built with Claude, presented about the stack.
- Figma/Power Pages/Fuse-hosted versions can come later from this as the spec.
